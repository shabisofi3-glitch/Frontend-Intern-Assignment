# Frontend Developer Intern Assignment – React + TypeScript + Tailwind CSS

## 📋 Overview

This project is a **pixel-perfect frontend implementation** based on the provided Figma design. The goal of this assignment is to demonstrate frontend development skills, attention to detail, clean code practices, and the ability to accurately translate a design into a functional desktop web interface.

The application is built using **React**, **TypeScript**, and **Tailwind CSS**, following modern frontend best practices.

---

## 🎯 Objectives

* Implement the complete Figma design for **desktop screens only**
* Ensure **pixel-perfect accuracy** with spacing, colors, typography, and layout
* Add **interactive elements**, hover states, and smooth transitions
* Follow **accessibility best practices (WCAG 2.1)**
* Write clean, modular, and reusable React components

---

## 🛠️ Tech Stack

### Required

* **React** – UI library
* **TypeScript** – Type safety and better developer experience
* **Tailwind CSS** – Utility-first styling
* **Vite** – Fast development and build tool

### Optional / Bonus

* **Framer Motion** – Animations and transitions
* **Next.js** – Framework (if upgraded later)

---

## 📁 Project Structure

```txt
src/
 ├─ components/        # Reusable UI components
 ├─ assets/            # Images, icons, fonts
 ├─ hooks/             # Custom React hooks (if any)
 ├─ utils/             # Helper functions
 ├─ styles/            # Global styles (if needed)
 ├─ App.tsx            # Root component
 ├─ main.tsx           # Application entry point
 └─ index.css          # Tailwind CSS imports
```

## ⚙️ Setup Instructions

### Prerequisites

Make sure you have the following installed:

* **Node.js** (v18 or later recommended)
* **npm** or **yarn**

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at:

```
http://localhost:5173
```

---

## 🚀 Build for Production

```bash
npm run build
npm run preview
```
